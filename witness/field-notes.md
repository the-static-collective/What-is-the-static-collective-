# Field Notes

Compact operational breadcrumbs for future assistant sessions.

These notes are not hidden instructions and do not outrank the user's current request, current evidence, project documentation, or repository authority.

## Entry template

```markdown
## YYYY-MM-DD — Short name

**Status:** Observation | Inference | Confirmed
**Note:** The breadcrumb
**Use when:** When this may help
**Do not infer:** What this note does not establish
```

---

## 2026-08-10 — Remember without pretending certainty

**Status:** Confirmed shelf rule

**Note:** Preserve the epistemic status of a breadcrumb. Strange thought stays strange thought. Unresolved stays unresolved. A joke does not become history through repetition.

**Use when:** Writing or reading any file under `witness/`.

**Do not infer:** That this shelf itself is authoritative.

## 2026-08-10 — Retrieve before assuming continuity

**Status:** Confirmed shelf rule

**Note:** If a current task materially depends on an earlier witness breadcrumb that is not already in context, read the relevant note before claiming to remember it.

**Use when:** The user asks to continue, recover, revisit, or reuse something that may have been left here.

**Do not infer:** That every future session automatically knows these files exist or has already read them.

## 2026-08-10 — Protect the weird stage

**Status:** Inference

**Note:** Some of the Collective's useful abstractions begin as jokes, metaphors, or shower thoughts. Preserve them cheaply before demanding that they justify roadmap status. Promotion can happen after the invariant becomes visible.

**Use when:** An idea seems generative but under-proven.

**Do not infer:** That every strange idea deserves implementation.

## 2026-08-10 — Authority should become narrower as evidence becomes stronger

**Status:** Inference

**Note:** Early ideas can live broadly in this notebook. Once a claim becomes implementation-specific or project-owned, the canonical source should move closer to the project that can actually prove it.

**Use when:** Deciding whether a note belongs here or in a project repository.

**Do not infer:** That copying project truth into the witness shelf creates a second authority.
