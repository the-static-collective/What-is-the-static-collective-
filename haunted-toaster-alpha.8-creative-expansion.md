# Haunted Toaster — alpha.8 Creative Expansion

alpha.7 has crossed from experiment into preserved ancestor. The next Haunted Toaster version should stop spending its energy proving the existing visual composer and instead build a bounded new generation on top of it.

> **Same proven creature. New way to summon it. New relationship to the source image. Better proof that the appliance actually contains what we built.**

Implementation authority remains in the Haunted Toaster repository. The canonical release design is `docs/superpowers/specs/2026-08-13-alpha8-creative-expansion-design.md`; project code, receipts, and current GitHub evidence outrank this notebook page.

## Target

`0.5.0-alpha.8`

Known-good ancestor: `archive/gold-star-renderer-alpha7`.

The alpha.8 release is a coordinated set of bounded slices rather than one giant renderer branch.

## 1. Failure evidence becomes insurance

The historical Windows FFmpeg `0xC0000005` crash is no longer required to reproduce before the project can move forward.

The durable requirement is evidence preservation: if the native failure returns, the failed performance must leave enough graph, score, timeline, arguments, stderr, build identity, and progress evidence to isolate the responsible seam.

PR #119 / issue #116 own that diagnostic line.

> **Preserve the failed performance before trying to teach it not to fail.**

No speculative crash workaround belongs in alpha.8 without a newly preserved specimen supporting it.

## 2. UI Witness Gate first

Before changing the largest visible surface, make renderer appearance part of build evidence.

Issue #122 / PR #124 remain the prerequisite:

```
production renderer assets
  -> deterministic browser witness
  -> screenshot comparison at commit SHA
  -> Vercel preview witness
  -> packaged Electron witness where native boundaries matter
```

The browser surface is not a web edition of the Toaster and owns no generation law. It exists so a change that claims to alter what the human sees produces something directly inspectable.

## 3. Seven Toast Feels / Toastmoods

The normal starting furniture should move beyond Porchlight / Wire Orchard / Absolute Residual while preserving those systems as ancestry and compatibility.

The new entry surface is:

* six ordinary burnt-toast mood choices;
* one larger seventh **MADD CLOWN CRAZY SLOTS** choice.

Core law:

> **Toast Feel biases the creature. It does not dictate the creature.**

A Toast Feel is not a complete preset. It applies bounded deterministic pressure across lawful creative axes and lets the existing six-up system discover the actual candidate.

MADD CLOWN means maximum lawful surprise through already-proven STOMP / outer-rail machinery, not ambient randomness.

The selected Toast Feel identity/version must survive selection → six-up → accepted candidate → final render → receipt.

Before cutover, interface identity must be decoupled from DOM furniture through one stable manifest shared by UI, generation handoff, receipts, and tests.

## 4. Native Color Witness enters alpha.8

The prior staging note kept Native Color behind the package line while alpha.7 was still being mined. That field-mining phase has now done enough work to justify a bounded first proof.

> **The photo is a witness, not just fuel.**

> **Stylization may compress the source, but it should sometimes decompress and let the source testify again.**

The alpha.8 cut remains deliberately small:

```
source image bytes
  -> deterministic NativeChromaticProfile
  -> source-relative chromatic relationship
  -> existing Color Drift
  -> bounded native-color decompression window
  -> shared preview + production compiler
```

The profile should use ordinary deterministic image statistics rather than semantic vision. No face/object segmentation is required.

The first relationship vocabulary should prove distinct source-relative behavior such as echo, counterpoint, or chromatic drain. At least one deterministic temporal event must visibly return toward the photograph's native chroma.

Native color is an event and compositional witness, not a permanent realism requirement.

Toast Feel may bias the relationship or allowed chromatic distance, but must not dictate an exact palette or reveal schedule.

## 5. Render choices remain transport choices

Keep the user-facing output distinction narrow:

* **Universal — H.264** as default;
* **Efficient — HEVC (experimental)** as optional.

Transport carries the same accepted haunt differently. It must not change visual semantics.

Do not respond to the alpha.8 expansion by turning topology, motion, palette, material, camera, and temporal density into a conventional wall of controls. Those remain the vocabulary explored by Toast Feel, six-up, locks, mutation, and admitted scores.

## Listener boundary

Keep the landed Listener parity/hardening work and human-anchor authority.

Do not make alpha.8 depend on the deeper Listener research backlog: wrong-chorus structure, vocal-biased recovery, broad threshold tuning, or Witness Session expansion remain later work.

## Release witness

The version is ready when one coherent packaged specimen proves:

```
Gold Star remains recoverable
  -> failure-evidence floor exists
  -> browser UI witness passes
  -> Toast Feel reaches six-up and the final receipt
  -> NativeChromaticProfile is deterministic
  -> source-relative color behavior is visible
  -> native color visibly returns at a lawful recorded event
  -> preview and final render agree
  -> Universal render succeeds
  -> Windows package matches the accepted UI/evidence boundary
  -> version becomes 0.5.0-alpha.8
  -> exact proven main commit receives v0.5.0-alpha.8
```

## Explicitly outside alpha.8

Compression Pressure, Dynamic Camera Variance, Linear v2 / Elastic Spine, deeper Listener structure, semantic/local color zones, Haunted Memory, Fallible Witness, Closed Witness Loop, foreign-video assimilation, Exact Return, and two-parent breeding remain valid later work.

The release should stop expanding when three new human-visible truths are present:

1. **I can summon the Toaster through a richer mood surface.**
2. **The source image's own color can matter and return.**
3. **What the accepted interface and receipt claim is what the packaged appliance actually executed.**

Then ship and mine the next field rather than adding another research lane.
