## Field verdict

Alpha.8 has crossed an important threshold: the renderer can already produce exceptional work, but the field corpus also exposes distinct weaknesses that should remain separate problems rather than becoming one broad rewrite.

The current direction is:

* preserve the exceptional visual composer;
* mine first-pass motion/topology pressure rather than globally damping it;
* calibrate MADD CLOWN by perceptual consequence, not parameter extremity alone;
* harden Listener context/confidence using human witness;
* give topology families minimum identities without imposing creative ceilings;
* keep #116 evidence-first until the native FFmpeg seam is actually isolated.

This is evidence that restraint can be a first-class aesthetic lane. The renderer does not have to begin at maximum activity to feel haunted or alive.

## Negative and calibration specimens

### Jesus Radio — negative control

The weakest overall run in the current batch.

MADD CLOWN produced a technically unusual but perceptually low-action creature: no atmosphere, locked camera, still motion, frozen temporal density. Listener placed only 19/50 lyric lines, while human witness reported some accepted placements as temporally wrong.

Two separate lessons:

1. **parameter extremity is not the same as visible consequence**;
2. **accepted match is not the same as correctly located match**.

Do not fix either problem by simply maximizing motion or by treating machine confidence as authority.

### Doves Crybox — leading-island Listener specimen

A first cue was accepted at `0:00–4.78`, followed by roughly 21.8 seconds of silence before cue 2. That is strong structural evidence of a suspicious opening island.

The desired law is not “ban zero-start lyrics.” A real song may begin singing immediately. Instead:

> a cue at/near zero plus an unusually large gap to the next cue should become review evidence unless stronger transcript or human-anchor evidence supports it.

### Base Code Bloom — chorus-island specimen

Strong refrain matches can coexist with large unresolved spans. Listener evaluation therefore needs to keep **coverage**, **placement confidence**, and **human-audible correctness** distinct.

## Listener laws emerging from the field

The same packaged appliance has produced both excellent and poor lyric behavior. That moves the diagnosis upstream of subtitle rendering and toward matching/context/calibration.

Preserve these laws:

* `matched` does not automatically mean correctly located;
* review count can under-report human-audible mismatch risk;
* repeated chorus/refrain material needs stronger sequence-position skepticism;
* first-cue-at-zero is contextual evidence, not an automatic error;
* human anchors are authority; machine confidence is evidence;
* prefer unresolved timing over confidently invented timing.

These findings extend the Listener mining already recorded in #113 rather than replacing it.

## First-pass topology / motion pressure

Several field runs felt more aggressive before the user Mutated or CONVERGEd. The emerging hypothesis is not that topology should be calmer by default; it is that an untouched first-pass candidate can sometimes **overcommit to its initial motion law**, while a descendant accidentally restores better balance.

Do not globally damp the engine from this observation. Preserve aggressive candidates as legal. Mine whether the six-up needs better coverage of settled/resting states or whether some base-axis combinations need a perceptual balance check.

The Habbits is a useful counterexample: restraint at the beginning, followed by earned motion, can be exceptional.

## MADD CLOWN — perceptual consequence floor

Jesus Radio exposes a useful distinction:

> **maximum lawful surprise should guarantee perceptible consequence, not maximum activity.**

A future MADD CLOWN check may need to ask whether the chosen combination creates an unmistakable visible departure. It should not dictate which axis provides that departure and should not become another hidden preset or chaos engine.

## Linear topology — floor open, ceiling open

The field corrected an earlier over-specific interpretation.

Linear does **not** need to remain a perpendicular two-bar cross. Parallel lines are good too, and the number of line-forms may grow arbitrarily.

The minimum identity is simply:

> **Two lines is a floor, not a shape.**

When `linear` appears:

* baseline multiplicity is at least two legible line-forms;
* parallel, perpendicular, crossing, skewed, mirrored, offset, or other relationships are all legal;
* line count may be `2..N`;
* mutation may duplicate, split, bend, echo, shear, fragment, braid, lattice, phase, or otherwise get strange;
* Mutate / CONVERGE may grow freely from the lineage;
* a single lonely line should not be the assumed standard.

This is preserved as executable future slice [#128](https://github.com/the-static-collective/the-haunted-toaster/issues/128).

## Native FFmpeg crash — Humble Genius witness

Humble Genius first reproduced the recurring Windows native failure:

```
ffmpeg.exe exited with code 3221225477
0xC0000005
~4.0–4.3 s
```

This time the alpha.8 failure bundle survived with the exact graph, args, score, timeline, stderr, source probes, and process metadata. That moved #116 from broad suspicion to a falsifiable hypothesis.

The failed graph contains `dynamics-magnetic-v1`, whose per-frame scale oscillates toward and below the fixed crop dimensions near the observed failure window. This is a strong **hypothesis**, not yet proof.

The later successful Humble Genius Linear render is a same-media control. It strongly argues against universal WAV/image/appliance failure, but because several graph axes changed it is not the one-variable test.

Next proof remains:

> replay the failing candidate while changing only `magnetic -> inertial` (or one equivalent safe control), then observe whether the native crash survives.

Keep #116 open until that isolation is witnessed.

## Frontier

The next renderer/Listener work should grow from this corpus rather than erase it:

1. Implement Linear multiplicity floor with open mutation ceiling (#128).
2. Continue Listener field mining before threshold tuning: leading islands, repeated-section mismatch, short lines, human-anchor re-contextualization.
3. Investigate first-pass motion/topology pressure without globally damping creative freedom.
4. Define a perceptual-consequence witness for MADD CLOWN that does not prescribe a particular effect.
5. Run the one-variable Humble Genius crash isolation under #116.
6. Preserve keeper specimens as regression references: Base Code Bloom, Mutation Seed, The Habbits, and the accepted Linear controls.

The field lesson is increasingly consistent:

> **Protect minimum identity at the floor. Leave the creative ceiling open.**
