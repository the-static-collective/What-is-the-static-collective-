## Entry

This is an **editorial, source-linked, deliberately noncanonical companion** to the existing [Living Git Map](https://the-static-collective.gitbook.io/the-static-collective-docs/living-git-map/atlas). It is not a replacement GitHub scraper, a master program over other projects, or a claim that all branches work together.

- **Terrain (machine observation):** [Public Git inventory](https://the-static-collective.gitbook.io/the-static-collective-docs/living-git-map/atlas/generated) and the [machine-readable snapshot](https://github.com/the-static-collective/What-is-the-static-collective-/blob/main/atlas/generated/public-index.json). Snapshot seen 2026-10-22 12:58 UTC: **86 public repos · 2,026 branch refs · 953 open PRs**. Counts describe the *snapshot*, not present authority or runtime health.
- **Meaning (editorial synthesis):** these pages connect a bounded set of verified public project and PR sources. *Not all 2,026 branch bodies have been read.*
- **Operator (human):** the human and each project owner decide reception, trial, release and canon. This wiki never does.
- **Visibility:** the public edition names and links only publicly surfaced repositories. Restricted material is deliberately excluded.

## Pattern observed across distinct laboratories

**Particular / event → owned evidence → declared transformation → receiving party decides → separately recorded consequence / refusal → attributable return.**

This is an **editorial pattern**, *not* a technical claim that a universal adapter, shared runtime, production deployment or unified organization exists. Each repository can implement, reject or reinterpret it locally.

## Four useful separations

1. **Atlas is observation.** Branch-head movement and open PR count have no authority semantics.
2. **planZ is planning.** A proposed roadmap is not a commitment by a restaurant, church, meeting host or donor.
3. **CANNON is selection pressure.** The spelling distinguishes a proposed owner-selected CANON FIELD from a single branch-based claim. Git main is not canon; signing is not truth.
4. **Abundent is a potential human front door.** A local printable card is not itself a public deployment, consent record, or fulfilled need.
