## Edge law

- **Descriptive:** READ / OBSERVE / PROPOSE / RECEIVE / REFUSE / ADMIT / APPLY / RELEASE are not interchangeable.
- **Source:** every edge must point to the repo, branch or PR that declares it.
- **Temporal:** an open PR and a deployed release can coexist; track them as different states.
- **Permission:** one project cannot grant another project's authority by naming it.
- **No forced convergence:** shared vocabulary is not evidence of one master product.

**Potential graph engine:** store source-target, exact evidence URL, relation type, capture date, maturity and receiving-owner disposition; render edges only when sufficient evidence supports them. This page is a human-first prototype, not a machine-verifiable graph.
