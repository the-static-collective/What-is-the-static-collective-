# Visual Phrasing — Cool Is an Event

The Haunted Toaster is increasingly behaving less like a generator and more like a composer. The next useful abstraction is **visual phrasing**: cool moments derive force from preparation, contrast, consequence, and memory.

## Core law

> **Cool is not a state. Cool is an event with preparation and consequence.**

If every frame is maximally strange, loud, fast, saturated, fractured, or shaken, then no individual moment can actually land. Restraint is not the absence of composition; restraint is what creates contrast.

A useful phrase cycle is:

> **withhold → imply → build → strike → decay → leave residue**

This should be treated as a compositional grammar rather than a fixed six-step template. Different songs and sections may omit, repeat, compress, or invert phases.

## Tension and release

Visual tension can come from holding something back:

* topology remains coherent before fracture;
* camera remains legible before a burst;
* palette withholds a major drift;
* atmosphere stays sparse before filling;
* motion preserves headroom instead of spending its maximum immediately;
* repeated sections retain recognizable ancestry instead of resetting.

Release is not necessarily “less.” It can take at least two opposite forms:

1. **Arrival** — the giant thing finally happens.
2. **Absence** — the giant thing stops, exposing silence, stillness, emptiness, or residue.

Both are valid releases because both depend on what came before.

## Preparation makes impact legible

A snare hit matters visually because the frame was comparatively stable before it. A violent topology shift matters because the topology had been holding itself together. A returning chorus matters because it remembers the previous chorus rather than merely replaying or resetting it.

This suggests an important renderer principle:

> **Do not spend the whole expressive range merely proving that the song is energetic. Preserve enough contrast for later events to mean something.**

That principle connects directly to Compression Pressure, inferred event lanes, Dynamic Camera Variance, Possession Arc, Color Drift, and section recurrence.

## Consequence and residue

A strong event should be allowed to change the state that follows it.

Possible residue includes:

* a topology that returns slightly damaged or reorganized;
* a palette that keeps a trace of the previous shift;
* camera damping that takes time to settle;
* atmosphere particles that linger after the triggering event;
* a returning section that behaves as a descendant of its earlier form;
* temporary reduction in motion after a major peak, making the release visible.

The event should not simply disappear when its trigger ends. Its aftermath can become part of the next phrase.

## Memory turns repetition into composition

Section recurrence is especially important. A repeated chorus should not necessarily reset to an identical visual state. It can return as a recognizable descendant:

* same family, altered pressure;
* same topology, changed material;
* same camera disposition, different modulation;
* same palette family carrying residue from the intervening section.

This creates visual memory without requiring literal repetition.

## Relationship to current response work

This law should sit above individual effect systems.

* **Compression Pressure** preserves low-floor activity while protecting peak headroom.
* **Dynamic Camera Variance** gives camera motion phrasing rather than static intensity.
* **Inferred control lanes** identify musically meaningful event evidence.
* **Possession Arc** provides categorical changes that can function as phrase-level decisions.
* **Color Drift** can withhold, accumulate, or release chromatic tension.
* **Musical structure / recurrence** can give returning sections ancestry and consequence.

None of these should be forced to fire merely because evidence exists. Composition includes choosing **when not to be cool**.

## Working compositional questions

Before spending a large visual event, the system should eventually be able to ask, implicitly or explicitly:

* What has been withheld?
* What is currently building?
* Is this event stronger because of contrast?
* What headroom remains afterward?
* What should decay slowly instead of snapping back?
* What residue should the next section inherit?
* If this section returns later, what should it remember?

## Release-scope note

This is a design law, not an instruction to rewrite the current Gold Star renderer before package release. Preserve the known-good behavior, continue field mining, and use this law to judge later response changes.

The immediate package line remains:

> **hold renderer → Listener UI → Toast Moods → package candidate**

The deeper goal after that is not simply more visual activity. It is stronger **visual phrasing, tension, release, and consequence**.
