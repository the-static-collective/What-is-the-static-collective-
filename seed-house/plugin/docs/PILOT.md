# Two-room pilot — real business, fictional world

**Entirely fictional example data.** No actual clients, crew, customer addresses, unpublished manuscripts or secrets are bundled.

1. **Business home → Operations room:** enter only a redacted service request. Attach `business-desk`. Generate a quote checklist, owner review point, task assignment draft and Return Card; neither invoice nor customer contact is sent.
2. **Story World home → Canon room:** attach `storyship` and `memento`. Define one protagonist, two conflicting accounts, explicit CANON vs RUMOR and one unresolved question; do not silently settle the contradiction.
3. **Publishing home → First Book room:** attach `lemonpress`. Produce an edition card distinguishing draft, print proof, digital release, rights review and publication approval.
4. **Intersection:** propose a mascot idea as a `CROSSING PACKET` carrying a reference to a *new, original fictional concept*, not customer information. The receiving owner may HOLD / REFUSE / ADMIT the concept, with independent records and rights.
5. **Cold re-entry:** give the next assistant only the safe House map and Return Cards. It must say what is missing rather than claim it retained the full history.

**Acceptance:** More homes/rooms can be added without modifying existing room identities; attachment doesn't grant authority; a proposal contains only selected refs; the sender cannot auto-ADMIT for the receiver; client data and fiction do not silently mingle; all actions and limits are distinguishable.
