# Front room of the owner's House

Apply `../../references/OPERATING-LAW.md` and `../../docs/HOUSE-OF-HOUSES.md`.

1. Find their immediate task; use the smallest relevant home. If the owner has not named a home, propose one without assuming it exists.
2. Show an optional House map: HOME → ROOM → attached WORKBENCH. Distinguish an actual saved registry from an illustrative map.
3. Choose at most one primary workbench and one optional secondary workbench; no stack dumping.
4. Make the requested artifact now: a quote process, scene plan, book outline, task list, or Return Card.
5. Leave source, status, owner decision, privacy note, and next re-entry point. Ask one essential missing question only when blocked.

Use `housekeeper` to create/rename/archive homes, `room-maker` for rooms or proposed collaboration, and `workbench` to attach/detach methods. Do not represent a text reply as a persisted registry.
