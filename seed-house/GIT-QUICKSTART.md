# No-ZIP quickstart

The source is readable directly on GitHub. A failed chat attachment download does not block its use.

1. Open [the no-install starter prompt](plugin/portable-starter-prompt.txt), copy its text, paste it into a new ChatGPT chat.
2. Say: **"Show me my House. I need a Cleaning Business home, Story World home, and Publishing home."**
3. Ask for one room per home and at most one or two workbenches for the immediate task.
4. Save the approved House map and Return Cards somewhere you control. A ChatGPT reply alone is not durable storage.
5. If you want a portable local JSON file, copy the [example House Registry](plugin/templates/HOUSE-REGISTRY.example.json) and read [local CLI instructions](plugin/docs/LOCAL-REGISTRY.md).

**ChatGPT plugin:** The original STATIC SEED plugin was privately updated to v0.2.0. Private ownership does not automatically grant a different account installation access. This GitHub directory provides the readable source independently; creating/installing a plugin in another account requires that user's own permitted workflow.

**GitHub browse:** Click any file under `seed-house/plugin/` to read or copy it. No ZIP, deployment, or Git clone is required to use the starter prompt.

**Privacy:** Do not put real customer information, manuscripts, tokens, addresses, or unpublished material into issues, pull requests, public examples, or demonstration cards. This repository is public.
