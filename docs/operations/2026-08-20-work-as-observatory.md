# Work as Observatory — Whole-World Integration

**Status:** dated operator note — 2026-08-20  
**Authority:** none

World Cut 001 provides a concrete example of what high-effort Work reasoning is unusually good for in the Static Collective: reconstructing a world that is distributed across many local authorities **without turning the reconstruction into a new authority**.

The run traversed 59 visible repositories, GitBook, 19 open pull requests, 97 open issues, 45 closed-unmerged pull requests, project status manifests, and exact-head evidence. The valuable output was not code volume. It was discrimination:

- landed versus candidate versus projected;
- truthful-but-stale versus currently fresh;
- healthy ancestry versus recoverable loss;
- repeated question versus falsely unified implementation;
- human-held gate versus missing automation;
- constitutional convergence versus superficial resemblance.

That supports a practical routing convention:

> **Use whole-world reasoning when the world-map itself is the hard problem. Use ordinary execution lanes once the next bounded crossing is known.**

A useful current shorthand is:

```text
Chat          discovers
Deep Research excavates
Codex         builds
Work          integrates worlds
Sol Max       adjudicates when integration itself carries semantic blast radius
```

This shorthand is **not constitutional vocabulary**. Product surfaces, models, names, credit prices, and capabilities can change. The reusable law is task-shaped:

- bounded implementation should not consume the constitutional court;
- cross-project semantic adjudication should not be delegated to a shallow mechanical sweep merely because it produces more output;
- a high-effort observer should return a dated decision/witness artifact and then relinquish execution authority.

## Relationship to Sol Max Reserve

`Sol Max Reserve — Reasoning-Sensitive Work` already says to reserve deepest reasoning for decisions whose mistakes propagate farther than their implementations, and calls that reserve a **constitutional court, not a coder of last resort**. World Cut 001 extends that convention with a second proven lane:

**whole-world constitutional archaeology / awareness cuts** — when enough independent projects exist that the hard question is what has actually become constituted across them.

The output should remain an evidence-bound World Cut, contradiction matrix, promotion verdict, or bounded next-crossing list—not a giant implementation patch.
