# STACK² 026 — Breath Atlas Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Deliver a reproducible branch-level evidence lens over the Static Collective's existing verified-public Living Git Map, with explicit uncertainty and no donor execution.

**Architecture:** Reuse `atlas/generated/public-index.json` as the sole existing public topology owner. Build isolated Python standard-library validation, pure evidence projection, and deterministic Markdown/JSON rendering. All branch-inspection claims are exact-SHA, source-linked manual observations; no live repo crawl is part of this slice.

**Tech Stack:** Python 3.11+ standard library, `unittest`, JSON, Markdown, SHA-256.

**Spec:** `docs/superpowers/specs/2026-10-22-breath-atlas-026-design.md`

## Global Constraints

- Keep the new module independent from `scripts/refresh_git_atlas.py` and don't change `atlas/generated/`.
- The public atlas's verified-public snapshot is the only admitted repository/ref list. Account-accessible CANNON 025 inventory is NOT public input.
- At most eight focused repositories and 24 branch heads; fail closed on unexpected schema, mismatched repo/branch head pins, unknown record fields, and unsafe source paths.
- A README/file list/branch name is not test evidence. Missing data is `UNKNOWN` or `HOLD`; never `LIVE`, `MERGED` or `FIELD_WITNESSED` by inference.
- No network, dependencies, remote writes, donor source execution, private names, money, sensitive persons or simulated real-world accomplishments.
- No automatic authority assignment; exact per-branch SHA and inspection provenance always survive rendering.

## Review Focus

- Snapshot's `visibility` unexpectedly `private` or omitted: reject before producing public links (Task 1).
- A branch appears under a different case or changed SHA after refresh: fail closed, not silently rebind observations (Tasks 1, 2).
- An open PR head belongs to a fork or mismatched commit: don't treat it as a local exact match (Task 2).
- An inspection reports a successful run but lacks command, environment or witnessed exit: do not upgrade to tested (Tasks 1, 2).
- Malicious Markdown values or unsafe branch/path components: escape markup and percent-encode source link paths (Tasks 1, 3).

Before pushing any output from an account-accessible inventory, independently verify the public visibility and exact owner. **Never copy** the 102-candidate CANNON 025 census directly into `atlas/breath/`. One snapshot, even dated today, does not license later cross-account publicity.
