# World Cuts

World Cuts are **dated, immutable constitutional witnesses** of the Static Collective ecosystem.

They are not current-state databases, dashboards, or authorities. A World Cut records what an observer could support from declared evidence at one cut. When the world changes, create a new cut rather than editing an old one into apparent currentness.

## Rule

> **A World Cut may become stale without becoming false history.**

That rule composes with Projection Freshness Witness: current evidence may supersede the cut as a current-state description without rewriting what the cut actually witnessed.

## Non-authority

A World Cut cannot:

- mutate project state;
- merge or release;
- close a human gate;
- promote a pattern;
- supersede a project-owned canonical source;
- claim that later unobserved events were already true at its evidence cut.
