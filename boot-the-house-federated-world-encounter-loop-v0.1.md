# Boot the House — Federated World Encounter Loop v0.1

**Status:** draft project-backed design witness — not portable law, not implementation authority

> **The House boots when one person can move through several sovereign systems as one continuous world, and every boundary still remembers who owns what.**

## The move

The ecosystem now has enough independently proven organs to attempt one inhabited heartbeat:

```
Full Measure field
  -> bounded nearby doors
  -> human gesture
  -> TranchNode Intent Stroke decoding
  -> explicit human crossing confirmation
  -> Project0 World Encounter Envelope
  -> Corpus OS destination-local disposition
  -> return residue
  -> visibly changed Full Measure Garden
```

The design is intentionally **large in architectural reach and narrow in proof surface**.

## Constitutional shape

* **Full Measure** owns the inhabited World Layer and human-facing orchestration.
* **Authority Kit / Founder Node** may expose evidenced nearby doors; relevance remains non-authoritative.
* **TranchNode** may decode traversal intent; ranking remains non-authoritative.
* **Project0** owns identity / NAV / encounter-envelope law; crossing never transports sovereignty.
* **Corpus OS** owns destination-local admission, refusal, execution, and operational failure.
* **GitBook** preserves orientation and later evidence; it is not runtime authority.

Full Measure composes the experience but does not absorb donor authority.

## Transport decision

Current donor repositories do not expose one honest common published-package boundary. The first federation therefore uses **repo-owned local process adapters with versioned JSON request/result contracts**.

```
Full Measure Node server
   -> configured TranchNode adapter process
   -> configured Project0 adapter process
   -> configured Corpus OS adapter/session process
```

Each donor owns its executable entrypoint, validation, and disposition. Full Measure owns only invocation configuration and local application translation.

This avoids cross-repo source imports, premature package publishing, a new daemon, and a network/auth plane before one crossing is proven.

Local process transport is a mechanism, not universal law. A later room may use HTTP, MCP, WebSocket, local IPC, or a package while preserving the same authority boundaries.

## First proof

One person must be able to:

1. enter the Full Measure Garden;
2. see three metadata-only nearby doors;
3. gesture toward one;
4. see TranchNode's candidate decoding and ambiguity;
5. explicitly confirm the crossing separately;
6. produce a valid Project0 encounter envelope;
7. receive one real destination-local Corpus OS disposition;
8. return to a Garden whose visible state changed according to the recorded outcome;
9. inspect the evidence / reconstruction path explaining why it changed.

`admitted`, `refused`, `indeterminate`, `failed`, and **pre-destination validation failure** remain distinct.

A malformed encounter is not a constitutional refusal. A runtime failure is not a constitutional refusal. A refusal does not constitute the attempted destination state.

## Deliberate refusals

This design rejects:

* a new central `world-runtime` repository;
* a master global graph;
* copied Project0 / TranchNode / Corpus OS semantics inside Full Measure;
* gesture rank becoming permission;
* nearby-growth relevance becoming permission;
* fixture-backed participation being represented as live donor participation;
* automatic promotion of refusal residue into law;
* Multiverse NAV becoming a master constitutional map.
