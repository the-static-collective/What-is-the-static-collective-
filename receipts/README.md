# Receipts

Evidence worth preserving lives here when no project-specific receipt store is more appropriate.

A receipt should make a claim inspectable: what happened, what source or artifact supports it, and enough provenance to revisit the claim later. Prefer original machine evidence, hashes, links, or compact records over retrospective narrative.

Do not duplicate receipts that already have a canonical project-owned home.
