# Newsletter Bits

**Role:** portable visual postcards / newsletter-ready interactive fragments  
**Authority:** none  
**Posture:** exploratory, attributable, downloadable

This folder preserves the little interactive visual boxes that emerge during Static Collective work.

They are intentionally **not** canonical project specs. Each bit is a self-contained HTML artifact that can be downloaded, opened locally, embedded later, or adapted into a newsletter without turning the visualization into project authority.

## Contract

Each bit should:

- be a single self-contained `.html` file where practical;
- preserve the date it emerged;
- name its working idea clearly;
- link back to the slice / issue / native project roads that gave it context;
- label speculative or non-canonical material honestly;
- remain useful even if the underlying theory is later split, corrected, or falsified;
- avoid becoming a second source of truth.

## Naming

```text
YYYY-MM-DD-short-readable-name.html
```
