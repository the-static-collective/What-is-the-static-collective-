# Specimens

Concrete examples and field-test records that taught us something live here.

A specimen preserves the conditions, observation, and consequence of an encounter with a system or idea. Machine receipts can establish what happened; specimen notes can preserve what it felt like to use, what surprised the operator, and what emerged that was not anticipated.

Use a project-specific specimen store when one already exists. This shelf is for portable or cross-project evidence.
