# Authority Narrows as Proof Grows

**Status:** Constellation / exploratory

## Ingredients

- [Witness Field Notes](../../witness/field-notes.md): early ideas can live broadly, while stronger implementation truth should move closer to the project that can prove it.
- [Creative Field Laws](../../patterns/creative-field-laws.md): evidence, proposal, unresolved state, and protected anchors should remain distinguishable.
- The repository rule that project-owned implementation belongs in the owning project rather than being duplicated here.

## Resonances

A recurring movement appears:

```text
weak / early
idea can live broadly
        ↓ evidence
shared pattern or vocabulary
        ↓ implementation proof
strong / specific
canonical authority moves toward owning project
```

This is counterintuitive if authority is imagined as a prize accumulated by centralization.

Here, stronger proof often produces **more precisely located authority**.

## Tensions

Not every strong claim has a single project owner. Cross-project laws may genuinely belong in a shared pattern layer. Likewise, a project can implement a local form without owning the portable concept.

So “narrower” cannot mean “always lower in an organizational hierarchy.” It means narrower **scope of the claim that can be made canonically**.

## Possible traversal

```text
possibility
  --evidence-->
portable claim
  --implementation-->
scoped canonical truth
```

## Illumination

This arrangement suggests that provenance and authority may behave differently from confidence.

Confidence can increase while authority becomes more bounded:

> We know more, therefore we can say more precisely **where this truth belongs and where it does not**.

That is potentially a deep Static Collective architectural signature.

## Residual fog

- How should genuinely shared invariants be governed when many projects prove them independently?
- What happens when an implementation disproves or refines a shared pattern?
- Can authority be both narrow in scope and distributed across multiple canonical witnesses?

## Promotion routes

This should become a pattern only if the same authority movement repeatedly prevents duplication, hidden coupling, or overclaiming across several repositories.
