# Two Kinds of Evidence

**Status:** Constellation / exploratory — promoted by repeated field use

## Ingredients

* Specimen Notes: human field-test evidence about surprise, aliveness, fakery, manual intervention, expectation, and emergence.
* Receipts: inspectable evidence about what happened, provenance, version, execution, or derivation.
* Repeated Static Collective practice of preserving both operator encounter and machine trace.

## Resonances

One event can produce two materially different witness surfaces:

```
machine receipt
what happened in the system?

human specimen
what happened in the encounter?
```

The machine can often record exact versions, timings, hashes, decisions, outputs, and acceptance states.

The human can notice that something felt canned, unexpectedly coherent, misleading, alive, awkward, invisible, or worth preserving before the system has any metric for it.

Neither class automatically subsumes the other.

## Tensions

Human phenomenological evidence is rich but subjective and context-dependent. Machine receipts are precise about what they record but blind to anything outside their instrumentation.

Treating either as complete produces a different failure:

* human-only memory can repair history through hindsight;
* machine-only memory can preserve an exact trace of the wrong questions;
* machine execution evidence can prove that an effect was generated while remaining unable to prove that the effect survived into human perception.

## Possible traversal

```
encounter
   ├── machine trace ──> receipt
   └── lived trace ────> specimen note
                 ↓
        later comparison
                 ↓
         architectural learning
```

## Illumination

The interesting unit may not be “evidence” in the singular but a **paired witness** where mechanical and experiential records remain separately attributable and can be compared later.

Surprise becomes especially important. A machine receipt can tell us the run succeeded; the human note can tell us the success revealed a capability nobody had specified.

The converse is equally important: a receipt can accurately prove that a visual effect was generated and executed while the human witness accurately reports that the effect was not perceptible.

This is not contradictory evidence. It is **different authority over different layers of the same event**.

## Promotion specimen — Resolution Field / Dust

Haunted Toaster PR #201 produced a clean paired-witness conflict that materially improved diagnosis.

Two renders carried the same Dust atmosphere plan: 85 events and the same Atmosphere content hash. Machine receipts proved that Dust existed computationally and that Resolution Field ran at `0.25` and `0.5`. The human operator reported no visible Dust in either final video.

That comparison narrowed the failure downstream of Atmosphere generation and exposed a perceptual-preservation gap that structural CI could not close.

Portable lesson:

> **A machine witness should not be granted authority over a property it does not measure.**

For render systems, successful generation and execution are not equivalent to visible survival. For other systems, the same pattern may appear as data that was persisted but cannot be meaningfully recovered, an event that was emitted but never encountered, or authority that was recorded but never lawfully exercised.

## Residual fog

* How should conflicting machine and human evidence be represented without automatically privileging either?
* When do repeated subjective impressions justify a new measurement?
* Can agents contribute specimen-like encounter evidence without that evidence being confused with machine telemetry?
* Which perceptual properties can gain bounded automated witnesses without pretending those metrics exhaust human encounter?

## Promotion routes

The Resolution Field specimen provides one strong case where preserving both evidence classes materially improved diagnosis compared with either class alone.

Further promotion toward a portable pattern should look for the same shape in other domains:

```
mechanism succeeded
        ≠
intended consequence survived
```

When that shape repeats, the system should preserve both the mechanism receipt and an independent consequence witness rather than promoting one into authority over the other.
