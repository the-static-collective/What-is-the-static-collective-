# Johnny Appleseed 001 — Free Graph Seed Scatter

**Date:** 2026-08-23\
**Mode:** SEED\
**Status:** Primitive Incubator specimen; non-authoritative, intentionally sparse, and timestamped to the present moment.

## Why this exists

This is the first deliberate Free Graph seed scatter: preserve a few relations that still feel structurally alive now, without pretending the graph is complete or that recurrence has promoted anything into law.

The purpose is longitudinal. Re-enter this specimen later and ask what actually germinated, what died, what changed type, and what turned out to have been a seductive but wrong compression.

## Operating boundary

Only the current Free Graph primitive relations are used here:

* `connects`
* `descends-from`
* `tests`
* `bears-on`
* `constitutes`

Additional rules for this specimen:

* relation visibility does not transfer authority;
* no transitive edge is implied unless separately planted;
* absence of an edge is not a negative claim;
* a candidate pattern remains a candidate until evidence and admission say otherwise;
* every planted edge keeps a source road;
* GitHub/project-owned evidence outranks this projection.

## Re-entry test for a later run

When this page is encountered again, do not merely append more edges. Ask:

1. Which candidate nodes gained **independent** support from a materially different domain?
2. Which edges were contradicted, weakened, or revealed as merely metaphorical?
3. Did any candidate graduate into a portable pattern, executable proof, or project-local law?
4. Did any visible relation accidentally acquire authority it was never granted?
5. Can every surviving edge still reconstruct its source road?
6. Did any omitted field become the unexpected bridge that changes the neighborhood?
