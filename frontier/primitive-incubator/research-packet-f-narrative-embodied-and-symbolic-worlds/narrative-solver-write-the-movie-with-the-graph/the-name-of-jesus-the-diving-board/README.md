# The Name of JESUS — The Diving Board

Status: **pre-dive architecture / hypotheses frozen before infrastructure-assisted descent**.

This page is deliberately **not** the deep dive itself.

It constructs a board strong enough that the later dive can go very deep without confusing a sound, a spelling, a person, an invocation, an office, an authority claim, a divine-name claim, and a thousand years of reception.

The governing rule is:

> **Do not ask what “the Name of Jesus” means until we can say what the name is doing in that exact source.**

## Why this needs a board

“The name of Jesus” is not one research object.

At minimum it can mean:

## The first hard surprise — lexical ordinariness

`Iēsous` was not a uniquely identifying sound-string in the first-century Jewish world.

Tal Ilan’s Palestinian onomasticon documents the broad naming world of 330 BCE–200 CE from literary, epigraphic, and papyrological sources. Eran Shuali’s later synthesis notes evidence for dozens of persons called `Iēsous` in Judaea/Palestine, and Josephus’s _Life_ alone names six different people called Jesus.

So the first null is decisive:

> **Later uniqueness of the referent cannot be back-projected into lexical uniqueness of the personal name.**

The research problem is therefore not:

> Why was this an intrinsically unique magic word?

It is closer to:

> **How did one historically ordinary Jewish personal name become an unusually dense carrier of identity, invocation, authority, memory, textual reverence, and divine-name interpretation?**

## The form-history lane

Do not assume one pristine phonetic token traveled unchanged.

Track every attested form as its own object:

```
יהושע   Yehoshua / Yehoshuʿa
  ↓ name-history / shortening
ישוע    Yeshua / Yeshuʿa
  ↓ Greek representation
Ἰησοῦς  Iēsous
  ↓ Latin transmission
Iesus
  ↓ later vernacular histories
Jesus / Jesús / Gesù / etc.
```

The exact arrows need receipts. Do not let the diagram imply a single uniform spoken pronunciation at every stage.

Important controls:

* `Yeshua` is historically attested as the common short form associated with the older `Yehoshua` name-family.
* The Septuagint uses `Iēsous` for both Hebrew `Yehoshua` and `Yeshua` figures, including Joshua son of Nun.
* Later Hebrew names for Jesus (`Yeshu`, `Yeshua`, etc.) have their own reception histories and cannot simply be projected backward into the historical Jesus’s mouth or contemporaries without evidence.

## Joshua ↔ Jesus — real bridge, dangerous overclaim

This is not merely a resemblance.

In Greek textual transmission:

```
JOSHUA SON OF NUN = Ἰησοῦς
JESUS OF NAZARETH = Ἰησοῦς
```

That is a real linguistic continuity.

But:

```
same Greek personal name
!=
same historical referent
!=
automatic proof of intentional prophecy
```

The previously developed Moses → Joshua → Jordan → JTB → Jesus gate sequence belongs here as a **reception / typology lane** after the linguistic bridge has been established independently.

## Etymology lane — philology vs narrative activation

The Yehoshua/Yeshua name-family is historically connected with the Hebrew saving/delivering root `y-š-ʿ` and with a theophoric history involving the divine name in the fuller form.

Matthew 1:21 explicitly makes the name narratively operational:

```
call him Jesus
because
he will save his people
```

Do not collapse:

```
historical morphology
popular etymology
narrative wordplay
theological interpretation
```

A biblical author can **activate** a historically available name-relation without giving a modern historical-linguistics lecture.

### SCEVA-001 — the killer null

Acts 19 narrates itinerant exorcists attempting to use the expression:

> “the Jesus whom Paul proclaims”

and then narratively refuses the expected authority.

Whatever historical judgment is made about the episode, the literary topology is unusually clean:

```
CORRECT REFERENTIAL STRING
+
COPIED INVOCATION

!=

AUTHORIZED RELATION
```

Candidate law:

> **THE NAME IS NOT A PASSWORD.**

This belongs beside `SEED != KEY`.

## JESUS-BARABBAS-001 — referent null

A significant textual-critical case in Matthew 27:16–17 preserves the longer reading `Jesus Barabbas`; Robert E. Moses argues that the longer reading was likely original while warning against turning that textual conclusion into unsupported reconstruction of the historical prisoner.

This is almost purpose-built for the research architecture:

```
JESUS A
JESUS B

same personal name
radically different narrative referent
```

So:

> **A name identifies only inside an addressable relational context.**

### PHIL2-NAME-001

Question:

> What exactly is “the name above every name” in Philippians 2?

Do not pre-answer.

Candidate scholarly readings include:

```
personal name JESUS
κύριος / LORD
Divine Name / YHWH-bearing relation
status / authority associated with lordship
```

The text immediately places `Jesus Christ is Lord` beside universal knee-bending language that echoes Isaiah. Scholars including Bauckham, Capes, Collins/Collins, Gieschen, Soulen and others argue various forms of divine-name Christology; other scholars stress Jewish agency/name-bearing precedents and resist treating one name-bearing text as a complete ontological proof.

Boundary:

```
DIVINE-NAME ASSOCIATION
!= automatically
SETTLED ONTOLOGY

but also

YHWH-TEXT APPLICATION
!=
TRIVIAL HONORIFIC
```

The dispute is data.

### ROM10-JOEL-001

Map the source text before interpretation:

```
Joel: call upon the name of YHWH
Romans 10: discourse centered on confessing/calling on Lord/Jesus
```

The future dive must track exactly how the scriptural referent is handled in Paul rather than merely saying “Paul calls Jesus YHWH” or denying the possibility by fiat.

### EXODUS23-NAME-001

The messenger in Exodus 23 is said to bear God’s name.

That is a critical negative/neighbor control for any claim that:

```
BEARS THE NAME
therefore
IS IDENTICAL IN EVERY SENSE
```

But it is also a positive control showing that `NAME-BEARING` was a serious ancient category, not modern wordplay.

## Materiality — when the name becomes graphically exceptional

This lane connects directly to Qumran without claiming genealogy.

### Qumran comparator

Some Dead Sea Scrolls written in square Hebrew script switch to paleo-Hebrew specifically for the divine name. The Cave 11 Psalms Scroll, copied roughly 30–50 CE, is a clear example: its ordinary text is in the Jewish book hand while the Tetragrammaton is written in paleo-Hebrew.

Structure:

```
ordinary textual field
  ↓
NAME encountered
  ↓
graphic regime changes
```

### Christian nomina sacra

Early Christian manuscripts similarly mark a class of words—including God, Lord, Jesus, and Christ—with contracted forms and supralinear strokes.

Do not infer direct lineage from the Qumran practice.

Use it first as a structural comparator:

> **A community can encode a theological / reverential distinction materially by changing how a name is written.**

And preserve manuscript caution:

```
SPECIAL WRITING
!= exact theology automatically recoverable

NOMEN SACRUM
!= mere ordinary abbreviation by default

EARLY PAPYRUS
!= first-generation autograph
```

`P46` is especially useful because its nomina-sacra behavior is rich but not perfectly mechanically consistent; that irregularity warns against reading scribal marks as a perfect ontology detector.

## Departure → portable relation

The preceding Enoch | Elijah | Jesus work creates one hypothesis worth freezing now:

```
JESUS
  ↓ ordinary embodied presence ends / changes
DEATH → RESURRECTION → ASCENSION
  ↓
followers continue to invoke / confess / baptize / act
with reference to “the name”
```

Candidate structural hypothesis:

> **A name becomes a gate when it makes a nonlocal referent addressable again without requiring the referent’s ordinary local presence.**

But the Sceva control immediately bounds it:

> **Addressability does not itself confer authority.**

So the stronger model is:

```
NAME-FORM
   ↓
REFERENT RESOLUTION
   ↓
CLAIMED RELATION
   ↓
LOCAL ADMISSION / RECOGNITION
   ↓
AUTHORIZED OR REFUSED CONSEQUENCE
   ↓
RECEIPT
```

This is extremely close to current Gate / Toaster topology.

## Source-world isolation

The future dive must preserve four worlds before crossing them:

### WORLD A — Hebrew Bible / Second Temple Judaism

Joshua; theophoric names; divine-name writing; messenger/name-bearing; Qumran; Jewish ritual invocation; Enochic and mediator traditions; onomastics.

### WORLD B — earliest Jesus movement / New Testament

historical personal name; Gospel naming scenes; Paul; Acts; invocation; baptism; confession; scriptural reuse; divine-name/lordship arguments.

### WORLD C — early material Christianity

papyri; nomina sacra; inscriptions; codices; amulets; liturgical and ritual artifacts.

### WORLD D — later reception

Fathers; creeds; Jesus Prayer; icon labels; exorcistic formulae; amulets; mystical/devotional name theology; medieval and modern Hebrew naming; Islamic `ʿĪsā`; occult/esoteric reception.

Cross-world edges require explicit bridges.

## The board’s frozen hypotheses

Freeze before collecting the giant corpus.

### H0 — ordinary-label hypothesis

The personal name functions substantially like other common personal names; later density is layered onto it.

### H1 — authority-token hypothesis

The name becomes a portable token of delegated authority.

Pressure: if this is merely a token/password, why does copied invocation fail in Sceva’s narrative?

### H2 — relational-address hypothesis

The name allows an absent/nonlocal referent and relation to be addressed/re-entered; consequence depends on locally constituted relation rather than syllables alone.

### H3 — divine-name participation hypothesis

Some early Christian texts intentionally bring Jesus into Jewish Divine Name / YHWH-scripture structures.

Pressure with Exodus 23, Jewish mediators, Greek `kyrios`, syntax, manuscript evidence, and competing interpretations.

### H4 — late-sacralization hypothesis

Strong sacred-name mechanics are mostly later reception projected backward.

Pressure against very early Pauline devotional/name material and early manuscript marking.

### H5 — phonetic-essentialism hypothesis

One reconstructed original pronunciation uniquely contains efficacy/identity.

Strong nulls already exist: identity survives translation/transliteration across languages; historically multiple people share the same name; the textual traditions themselves operate in Greek `Iēsous`.

Do not reject until formulated fairly, but demand an evidentiary mechanism.

## The deepest-dive sequence

When infrastructure is ready, descend in this order:

```
0 RAW ATTESTATION
  exact characters / image / manuscript / date / provenance

1 FORM
  language / spelling / phonology / transliteration

2 REFERENT
  which person or entity does this token identify?

3 GRAMMAR
  syntactic construction / preposition / verb / case

4 FUNCTION
  naming / invocation / confession / ritual / quotation / title

5 CONSEQUENCE
  what changes in the narrative or practice?

6 INTERTEXT
  exact cited/alluded source and original referent

7 MATERIALITY
  graphic treatment / nomen sacrum / inscription / artifact

8 RECEPTION
  later interpretation, ritualization, polemic, devotion

9 STRUCTURAL COMPRESSION
  only now ask what law survives
```

## The sentence on the diving board

> **THE NAME IS NOT THE KEY. THE NAME IS AN ADDRESS. WHETHER THE ADDRESS OPENS A GATE IS A RELATIONAL QUESTION.**

Status: hypothesis, not doctrine.

That is why the future dive can become genuinely deep without becoming sloppy.

## Final boundary

The future dive must be allowed to discover something the board does not predict.

If all roads are forced to end at `NAME = DIVINE PASSWORD`, the board failed.

If all roads are forced to end at `NAME = ORDINARY LABEL`, the board also failed.

The question is not which doctrine can collect the most resonances.

It is:

> **What relation is actually traveling each time the Name crosses a boundary?**
