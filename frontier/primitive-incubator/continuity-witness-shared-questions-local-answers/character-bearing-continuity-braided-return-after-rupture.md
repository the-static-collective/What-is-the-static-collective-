# Character-Bearing Continuity — Braided Return After Rupture

**Status:** incubating cross-project projection with executable issues opened

**Artistic trigger:** Autodiscography lyric specimen `ReturnType<Self>` (2026-08-01).

**Executable authority:**

* Project0 #59 — [https://github.com/the-static-collective/project0/issues/59](https://github.com/the-static-collective/project0/issues/59)
* Band Runtime #17 — [https://github.com/the-static-collective/band-runtime/issues/17](https://github.com/the-static-collective/band-runtime/issues/17)

This page preserves the constellation. It does not outrank either repository.

> **Home is not sameness. Home is an attributable road through change, enough declared character to recognize the continuation, and a lawful address from which life can proceed.**

## The lyric seam

The song compressed two operations into one tiny pair:

```
returnTo(origin)
reEnter(us)
```

The first points backward.

The second points forward.

That distinction matters because the existing Collective already has strong neighboring laws:

* Attributable Transformation — continuity may survive change when the road through change remains attributable;
* [World Re-entry](../../../patterns/world-reentry-memory/) — meaningful participation may resume without restoring the old room;
* [Artifact Resurrection / Exact Return](../artifact-resurrection-exact-return.md) — preserved causes may reconstruct an artifact under explicit exact/lawful/partial return classes;
* Project0 Typed Continuity Braid — root closure, typed continuity, loss, breakage, plurality, and reconstitution;
* Project0 #27 Resonance Seeds — recognition can record preserved, transformed, absent, unresolved, and emergent marks without claiming exact-original identity.

The new pressure is therefore not another identity theory. It is smaller:

> **Can recognition after irreversible change preserve two lawful directions at once: a road back to attributable origin and a distinct address from which the changed continuation proceeds?**

## Exact Return, Re-entry, and Braided Return are different

```
EXACT RETURN
  reconstruct prior artifact/state

WORLD RE-ENTRY
  reconstitute enough truthful relation to participate again

BRAIDED RETURN
  recognize an attributable continuation after change
  while preserving:
    backward road -> origin
    forward address -> descendant
```

Braided Return must never silently claim:

* descendant = ancestor;
* recurrence = reset;
* re-entry = uninterrupted presence;
* resemblance = ancestry;
* recognition = authority transfer.

## Character-bearing particulars

The lyric's strongest pressure is that continuity may sometimes be recognizable through a **sparse set of exact particulars** rather than whole-state sameness.

A candidate **Character Profile** therefore does not ask:

> How similar is this thing to the old thing?

It asks:

> Which declared particulars survived, transformed, vanished, emerged, or remain unresolved?

Conceptually:

```
Character Profile
  mark A — required
  mark B — required
  mark C — optional
        ↓
transformation / rupture
        ↓
observation
  A preserved
  B transformed
  C absent
        ↓
local recognition policy
        ↓
recognized-continuity | not-yet-home | unresolved | refused
```

This must remain **non-scalar**. No identity percentage, personality score, similarity threshold, or embedding confidence gets to substitute for attributable lineage.

A local policy may say that certain declared marks are required for one recognition disposition. That policy is a bounded test, not a universal definition of selfhood.

## Character cannot manufacture ancestry

This page inherits the standing anti-overfit law from Attributable Transformation:

> **Difference may witness continuity. Difference never gets to manufacture its own ancestry.**

The complementary form here is:

> **Matching character may help recognize a road. Matching character cannot invent the road.**

A fresh unrelated artifact may reproduce every visible mark and still have no lawful continuity claim to the original.

The road must already be attributable through the existing continuity/addressing law.

## The braided receipt

Project0 #59 proposes a bounded receipt with two directional roles.

```
sourceRef
   │
   │ attributable transformation / rupture
   ▼
descendantRef
   │
   ├── returnPathRef ------> exact historical road toward origin
   │
   └── continuationRef ----> present constituted point for future change
```

The two refs should usually resolve to different semantic roles even when they live inside one causal graph.

### `returnPathRef`

Answers:

> How do I walk backward through the actual history that produced this continuation?

It closes over source roots, transformations, rupture evidence, and the evidence required to explain why this descendant is here now.

### `continuationRef`

Answers:

> From which exact changed present may future lawful participation proceed?

It should point to the descendant/current causal cut rather than cosmetically snapping the system back to origin.

This is the important asymmetry:

```
return remembers where we came from
continuation remembers where we actually are
```

## Rupture must remain visible

A return after interruption is not trustworthy if the system needs to erase the interruption to explain continuity.

Candidate rupture classes include:

* transport unavailable;
* process/runtime restart;
* missing projection interval;
* participant departure and re-entry;
* decoder/environment change;
* loss of non-required surface state;
* a required mark becoming unavailable;
* unresolved historical material that cannot be reconstructed.

A lawful continuation therefore preserves:

```
before
  ↓
rupture
  ↓
re-entry / replay / reconstitution
  ↓
changed present
```

not:

```
before
  ↓
[rupture deleted]
  ↓
before again
```

If required evidence is missing, `not-yet-home` or `unresolved` is a valid result.

## Medium-native conformance

The lyric contains another unusually useful design pressure: the bridge does not merely _describe_ resumability. It disconnects and returns in the musical structure.

That suggests a wider testing discipline:

> **When a medium can enact the invariant it claims, test the invariant through the medium itself rather than only through metadata about the medium.**

Examples:

* resumable runtime → actually interrupt it;
* artifact resurrection → actually regenerate the artifact;
* branch/re-entry system → actually leave and return without rewriting history;
* musical continuity → actually break the performance and require the resumed mix to carry lawful consequence of the pre-break history.

This is not a demand that Project0 become an audio, UI, or runtime framework. Project0 should only define the neutral conformance pressure.

The first medium-native witness is now queued in **Band Runtime #17**.

## Band Runtime specimen

The proposed first proof is deliberately literal enough to falsify the idea.

```
motif A admitted
      ↓
pre-rupture causal cut + mix
      ↓
FORCED DISCONNECT / RESTART
      ↓
resume from durable history
      ↓
replay only missing events
      ↓
new harmony B admitted
      ↓
post-rupture mix = A + B
```

The proof only counts if:

* A is not duplicated by reconnect/replay;
* the old causal-cut render remains unchanged;
* the rupture remains explicit in history;
* the new harmony depends on the changed present rather than rewriting the past;
* a resemblance-only fresh session cannot inherit the original ancestry;
* the exported receipt can walk backward to origin and forward from the resumed cut.

The governing sentence from the issue is:

> **The band comes back on the one. It does not pretend the silence never happened.**

## Why this is not the Coherence Profile

Project0 #9 asks a broader identity/governance question:

> How does identity survive growth without silent replacement or drift?

Character-bearing continuity is narrower.

It does not define purpose, authority, stewardship, or permissible change for a whole system. It supplies one possible evidence profile for recognizing a continuation under a declared policy after change has already been attributed.

The relationship may eventually become:

```
Coherence Profile
  broader identity / invariant / drift contract

Character Profile
  sparse recognition witness inside some continuity cases
```

But that relation remains experimental until executable fixtures prove it.

## Why this is not Resonance Seeds

Project0 #27 already knows how sparse marks can survive into different realizations and how recognition may classify marks as preserved/transformed/absent/unresolved/emergent.

Character-bearing continuity does not replace that.

Its extra question is specifically **continuity across an attributable source-descendant road**, including rupture and the paired backward/forward address.

A Resonance Seed can have many independent realizations with no claim that they are the same continuing object.

A Braided Return is only meaningful when a continuity road is already under examination.

## Smallest falsification set

The current proposed fixture family is intentionally adversarial:

1. **Material change, character survives** — required marks remain attributable; optional mark transforms; continuation recognized.
2. **Required mark disappears** — no silent substitution; result remains `not-yet-home` or unresolved.
3. **Resemblance without road** — unrelated object matches all visible marks; ancestry still refuses.
4. **Rupture survived** — interruption remains in history; replay is idempotent; earlier cut remains unchanged.
5. **Forward continuation** — future events descend from the changed present, not retroactively from the origin.

A useful primitive must survive all five.
