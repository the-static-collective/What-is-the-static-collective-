# Relational Coordinate — Sigils as Typed Projection Keys

## Compression

A sigil does not need to contain one flat meaning, nor seven unrelated meanings.

A stronger model is:

> **one stable coordinate can participate coherently in several typed relational spaces, with each lawful projection selected by an attributable lens.**

```
Σ = stable coordinate / sigil
O = Resolve(Σ, world_head)
L = {domain, relation, resolution, decoder_version}
P_L(O) -> typed projection
```

The governing boundary is:

```
projection != evidence != authority != consequence
```

A projection can become legible without becoming true, reachable, authorized, or executable.

## Why “relational key” works

A normal key does not contain the room. It establishes a relation with a particular lock.

Likewise:

```
sigil + typed lens -> intelligible projection
```

The same stable coordinate may therefore disclose different lawful views:

```
mathematical  -> operator / magnitude / transform
 topological  -> boundary / nesting / adjacency
     lineage  -> ancestry / descent coordinate
   narrative  -> recurrence / transition / role
cryptographic -> digest / commitment / verification coordinate
 world-state  -> discoverability / reachability / local posture
```

The formal terms **relational coordinate** or **projection key** are safer than _cryptographic key_, because the primitive does not inherently grant secrecy, capability, or access.

## Observer is not semantic authority

An observer may select a lens, but should not be allowed to invent the lens semantics ad hoc.

The selector should remain explicit and attributable:

* domain;
* relation or query class;
* resolution;
* decoder version;
* world/head against which the coordinate is resolved.

This converts contextual meaning from arbitrary polysemy into a falsifiable contract.

## Change the lens != change the object

This distinction is foundational:

```
ViewRotate(L, Σ)
-> another projection of the same O
```

is not the same operation as:

```
ObjectRotate(O)
-> O'
```

Changing the interpretive axis must not silently manufacture a descendant.

If `ROTATE`, `NEST`, `CUT`, `MERGE`, or another operator is constituted as a real transformation inside a domain grammar, that transformation requires its own attributable history and receipt.

## Free Graph fit

This model fits Free Graph precisely because Free Graph already keeps source identity, access/export posture, status, relation, and authority distinct.

Nothing here requires widening its five portable verbs.

Instead:

* lens semantics stay local in qualifiers/extensions until repeated executable pressure justifies promotion;
* choosing a projection cannot widen source disclosure;
* choosing a projection cannot promote authority;
* choosing a projection cannot silently change claim status;
* the projection records what became legible under a declared lens, not proof that the projected claim is true.

## Sealed Witness fit

The private-source pressure case gives the primitive a hard boundary rather than merely elegant semantics.

A cryptographic/provenance lens may expose:

```
stable source coordinate
commitment or digest
existence/timestamp witness
claimed relation
```

while the content projection remains closed.

So:

> **A source does not have to travel for its road to remain accountable.**

But the jobs remain separate:

```
digest != hiding commitment
commitment != truth
existence witness != authority
```

A sigil can help address those layers without collapsing them.

## Five negative controls

Before this deserves executable shared semantics, pressure it with five failures-to-cheat:

1. **Lens test** — hold `Σ` fixed and change the lens; projections may differ while object identity and ancestry remain stable.
2. **Object test** — hold the lens fixed and change `Σ`; the result must materially change so context is not carrying the whole answer.
3. **Version test** — change decoder semantics; the new projection must cite a new decoder version rather than silently rewriting old history.
4. **Authority test** — selecting any lens must not increase authority or capability without a separate local gate.
5. **Disclosure test** — a sealed source may expose provenance/commitment while content remains redacted; projection cannot widen `access` or `export`.

## Promotion discipline

Do not promote this because the metaphor is attractive.

Promotion should require at least:

* one deterministic specimen passing the five negative controls;
* a second materially different consumer reproducing the separation law;
* no widening of Free Graph's five verbs merely to encode domain semantics;
* evidence that the projection primitive reduces real ambiguity or duplication compared with ordinary typed fields.

Until then the portable sentence is enough:

> **One stable coordinate. Many lawful projections. No silent promotion between them.**

## Nearby work

This composes with existing work without overruling it:

* **Sigil Language — Geometry Becomes Speech**: shape meaning is separate from authority, identity proof, and ancestry;
* **Mathematics Before Number / eCODE μ0**: number is one typed dialect over a deeper relational kernel;
* **Pocket Web Hypermath**: typed links and path-sensitive traversal;
* **Free Graph**: provenance-first traversal with local authority;
* **Sealed Witness / commitment-carried provenance**: source accountability without forced disclosure.

The new compression is not that a sigil _means many things_.

It is that a sigil may become a **stable junction through which several independent grammars can address the same underlying continuity**.
