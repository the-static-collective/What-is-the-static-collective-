# Palimpsest Continuity — Shape Language & Witness Sigils

> **Status:** primitive incubator projection. The `national-treasure` repository case is the research authority for this slice; this page does not promote the proposal into Project0, TranchNode, Toaster, Corpus OS, or shared runtime law.

## The clue that survived the weirdness

The historical stack is more defensibly modeled as a **palimpsest** than as one concealed chain. Forms can survive while meanings change; meanings can survive while forms change; names can move independently of both.

For the eCODEsystem, the practical consequence is:

> **Do not attempt to prove sameness where the evidence only gives transformation. Preserve the transformation.**

This pressures a representation spine:

```
PARTICULARITY
  -> FORM
  -> RELATION
  -> REPRESENTATION
  -> TRANSFORMATION
  -> WITNESS
  -> CONTINUITY
  -> AUTHORITY (only where constituted)
```

Not every object reaches authority. A research specimen may stop at witness; a visual projection may stop at representation; an AI proposal stops before admission.

## Shape language v0.1

The National Treasure case also proposes an explicitly **invented** sixteen-primitive visual alphabet, addressable by hexadecimal nibble `0–F`.

These meanings are Static Collective design assignments, not claims about ancient symbols.

| Hex | Primitive            | Proposed meaning         |
| --- | -------------------- | ------------------------ |
| `0` | point                | particularity / specimen |

The useful abstraction is not the iconography alone. It is a grammar of declared operations such as `ROTATE`, `REFLECT`, `OVERLAP`, `LIGATE`, `CUT`, `NEST`, `BRANCH`, `MERGE`, and `PROJECT`, each able to name what survived and what was lost.

## Witness Sigils

A **Witness Sigil** is a deterministic geometric projection of an already-authoritative receipt digest.

Conceptual v0.1:

```
canonical SHA-256 receipt digest
  -> first 16 hexadecimal nibbles
  -> nibble 0-F maps to primitive 0-F
  -> fixed versioned geometric layout
  -> human-visible sigil + textual digest prefix
```

The boundary is strict:

* the digest remains canonical;
* the sigil is only a recognition cue;
* a sigil is not a signature;
* a sigil is not authentication;
* a visual collision never adjudicates identity;
* a solved symbol or puzzle never manufactures authority.

This gives a possible human-facing continuity surface for render receipts, canonical artifacts, archive labels, printed media, and clue packets while leaving verification boring and machine-checkable.

## Cicada rule

```
MYSTERY SURFACE
  strange / symbolic / optional

VERIFICATION SURFACE
  canonical bytes / hashes / signatures / receipts / source locators

AUTHORITY SURFACE
  explicit admission law / constituted actor / bounded capability
```

Mystery may invite traversal. It must never be the only route to legitimate authority.
