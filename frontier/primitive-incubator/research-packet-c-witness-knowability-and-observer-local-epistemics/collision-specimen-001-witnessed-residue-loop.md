# Collision Specimen 001 — Witnessed Residue Loop

**Status:** Draft frontier projection / design only. **Not implementation evidence. Not shared law.**

**Repository owner:** Full Measure — World Layer\
**Tracking:** [GitHub issue #21](https://github.com/the-static-collective/full-measure-world-layer/issues/21)\
**Canonical written design:** [`2026-08-18-collision-specimen-001-witnessed-residue-loop-design.md`](https://github.com/the-static-collective/full-measure-world-layer/blob/agent/collision-specimen-001-design/docs/superpowers/specs/2026-08-18-collision-specimen-001-witnessed-residue-loop-design.md)

## Question under test

> Can remembered non-success affect what becomes visible or thinkable next without becoming permission, truth, reachability, or authority?

The first specimen keeps the collision inside Full Measure. It does **not** combine Upper Room, TranchNOSE, Haunted Toaster, or donor-repository contracts into one experiment.

## Bounded loop

```
refused | indeterminate encounter
  -> durable WorldEncounterResidue
  -> read-only residual influence
  -> optional fixture-local declared-freedom descendant
  -> witness session
  -> compact relation re-entry seed
```

Required invariants:

```
constituted state unchanged
authority unchanged
reachability unchanged
residue attributable
influence read-only
descendant remains proposal
indeterminate remains unresolved
re-entry != occurrence
```

## Important design correction

The re-entry artifact reconstructs only the surviving **relation/ref graph**. It does not recreate vanished proposal bodies, donor responses, or historical occurrence.

Likewise, residue does not contain enough proposal content to manufacture a descendant. The optional descendant sub-proof therefore requires an explicitly supplied synthetic ancestor fixture and remains fixture-local in v0.1.

## Why this is still frontier

A passing Full Measure specimen would establish only project-backed evidence that these ideas can compose **here**. It would not automatically graduate Ghost, Witness Session, Declared-Freedom Descendant, Refusal Topology, Declared Witness Channels, or World Re-entry into shared law.

A second materially different domain must independently test any invariant before shared abstraction is considered.

## Evidence gate

Do not convert this page to an evidence specimen until the repository has:

* implementation on a reviewed PR;
* refused and indeterminate fixtures;
* deterministic replay proof;
* no-authority negative control;
* re-entry relation reconstruction proof;
* fresh repository verification after the final mutation;
* exact PR/merge commit and verification result.

Until then, the repository issue and design spec are the authoritative implementation boundary.
