# Research Packet C — Witness, Knowability & Observer-Local Epistemics

This packet asks what an observer could lawfully encounter, know, derive, witness, relay, or remain unable to access.

Working distinctions:

```
existence != knowability
availability != encounter
witness != authority
projection != source
local supportability != global truth
```

Current executable descendants such as 3rdi and MORTAL-ACTOR may illuminate these leaves without rewriting their historical formation.
