# Work as Observatory — Whole-World Integration

> **Status:** dated operator note · authority none.

Source note: [GitHub PR #26](https://github.com/the-static-collective/What-is-the-static-collective-/pull/26)

World Cut 001 demonstrated a useful division of labor: high-effort whole-world reasoning is unusually valuable when the difficult task is **integration and adjudication across already-existing local evidence**, not ordinary implementation.

The run's useful work was discrimination:

* landed vs candidate vs projected;
* current vs truthful-but-stale;
* healthy ancestry vs recoverable loss;
* repeated question vs falsely unified implementation;
* human-held gate vs missing automation;
* constitutional convergence vs superficial resemblance.

The durable routing lesson is:

> **Use whole-world reasoning when the world-map itself is the hard problem. Use ordinary execution lanes once the next bounded crossing is known.**

A useful current shorthand is:

```
Chat          discovers
Deep Research excavates
Codex         builds
Work          integrates worlds
Sol Max       adjudicates when integration itself carries semantic blast radius
```

This shorthand is intentionally **non-constitutional**. Product names, model levels, credit prices, and capabilities can change.

What may survive those changes is task-shaped: deep whole-context reasoning belongs where an incorrect synthesis could silently change the meaning of several local worlds at once. Once the judgment yields a bounded executable slice, implementation returns to the ordinary build/test/PR lane.

## Relationship to Sol Max Reserve

The existing Sol Max Reserve calls the reserve a **constitutional court, not a coder of last resort**. World Cut 001 adds a proven reserved lane: **whole-world constitutional archaeology / Awareness cuts**.
