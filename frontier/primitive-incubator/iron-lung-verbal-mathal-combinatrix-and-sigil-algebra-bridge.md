# Iron Lung — Verbal/Mathal Combinatrix & Sigil Algebra Bridge

**Status:** approved frontier slice; design only; no implementation authorization implied.

**Canonical project authority:** `the-static-collective/iron-lung`, draft PR #4 and `docs/superpowers/specs/2026-08-22-verbal-mathal-combinatrix-sigil-bridge-design.md`.

This slice extends the landed Recursive T5 Combinatrix / Heart-Lung design without replacing it.

The recovered machine already had three constitutional strands:

```
Braid
├── S — Substance
├── L — Lineage
└── A — Authority
```

and a bounded **Combinatrix** rather than an unbounded Cartesian explosion.

The new synthesis adds a second dimension:

```
verbal
mathal
```

The important correction is that this is **not three T5 models in a row** and not direct prose-to-equation translation.

The stronger hypothesis is:

> **Verbal and mathal forms are distinct, fallible projections of a deeper relational object. Recursive circulation between them may expose invariants, contradictions, gaps, topology, and residue that neither projection reveals alone.**

## Relational core before representation

Introduce a local relational object `R`.

Two projections may expose it differently:

\[ \pi\_V(R)=V ]

\[ \pi\_M(R)=M ]

and bounded interpretations may return:

\[ \iota\_V(V) \rightarrow R\_V ]

\[ \iota\_M(M) \rightarrow R\_M ]

They are not guaranteed inverses.

In general:

\[ \iota\_V(\pi\_V(R)) \neq R ]

and:

\[ \iota\_M(\pi\_M(R)) \neq R ]

That mismatch is not automatically error. It is **representation residue**.

The verbal surface may expose ambiguity or intent that the mathal surface hid.

The mathal surface may expose contradiction, topology, noncommutativity, or impossible constraints that fluent language hid.

Neither surface gains authority merely by representation type.

## Connector

The **Connector** is the witnessed crossing between representational worlds.

It is not an equivalence claim.

A Connector preserves:

```
source representation
projection / interpretation rule
result representation
residue
provenance
authority posture
```

Core distinctions:

```
projection != identity
translation != equivalence
agreement != authority
```

The Connector therefore lets unlike representations pressure one another without silently collapsing them into one ontology.

## Lung

The **Lung** recursively circulates through possibility.

One conceptual breath is:

```
R[k]
 ├─> verbal projection -> interpreted relation R_V
 ├─> mathal projection -> constrained relation R_M
 └─> preserve residue
          ↓
      S / L / A pressure
          ↓
        R[k+1]
```

Write one complete breath as:

\[ R\_{k+1}=\Psi(R\_k) ]

Then recursive depth becomes meaningful:

\[ \Psi^3(R), \Psi^{27}(R), \Psi^{81}(R), \ldots ]

A power is initially only iterated operator application / orbit depth. It is not automatically truth, authority, maturity, or magnitude.

## Heart

The **Heart** remains a different kind of edge.

Recursive possibility must not mutate constituted history by itself.

Let:

\[ H(B\_n,p,w) \rightharpoonup (B\_{n+1},r) ]

where `p` is a candidate, `w` is the required present warrant / witness supplied outside generation, and `r` is the receipt.

Therefore:

\[ p \in \Psi^k(B\_n) \not\Rightarrow B\_n \rightarrow B\_{n+1} ]

Compression:

> **Reachable in possibility is not entered into history.**

And the recovered law remains:

> **The Lung may breathe through possibilities. The Heart beats only when consequence becomes present history.**

## Addressable Absence

The recovered T5-shaped primitive becomes mathematically important here:

> **Do not erase the hole. Give it an address.**

A typed absence is not merely `null`.

Provisional gap families remain:

```
<gap:substance:*>
<gap:lineage:*>
<gap:authority:*>
```

A Sigil Algebra may eventually permit a CUT-like operation to preserve the wound:

\[ \operatorname{CUT}(X) \rightarrow (X', g\_i) ]

where `g_i` retains type, address, historical cut, boundary, surrounding relation, and closure requirements.

A later filling or repair does not rewrite the ancestor as though the gap never existed.

Do **not** call the gap algebraic zero yet. Zero carries obligations this object has not earned.

## Sigil Algebra bridge

The current Sigil Grammar exposes candidate operators such as:

```
CUT
NEST
BRANCH
OVERLAP
MERGE
ROTATE
...
```

The bridge is not that Iron Lung owns those operators.

It is:

> **Iron Lung can supply constitutional recursion and representational crossing; Sigil Mathematics can supply a candidate explicit algebra of transformations that one mathal projection may use.**

Operator order must remain visible.

In general:

\[ A(B(X)) \neq B(A(X)) ]

So:

```
CUT -> NEST
```

need not equal:

```
NEST -> CUT
```

History becomes part of the mathematical value rather than metadata attached afterward.

Rotation and recursion should also remain distinct candidate axes:

```
Psi^n    recursive application / orbit depth
ROT^k    orientation / phase / conjugate-like state
```

No stronger semantics are promoted yet.

## Fixed points, cycles, and partial convergence

A fixed point:

\[ \Psi(R)=R ]

means only **stable under this operator and present cut**.

It does not mean true.

A period-2 orbit:

\[ \Psi^2(R)=R, \quad \Psi(R)\neq R ]

may expose an actual unresolved incompatibility and must not be collapsed to the most recent state.

The verbal and mathal projections may also stabilize differently. For example, mathal structure may stop changing while verbal interpretation continues exposing distinctions, or the reverse.

That disagreement is useful evidence about representational limits.

## Emergence belongs in perception, not ancestry

The neighboring shape-grammar thread adds one major law.

Composition may expose a recognizable subshape `Q` that was not an explicit operand in the generative expression.

That does not authorize retroactive ancestry.

```
exact generated geometry G
        ↓
perceived subshape Q
        ↓
derived/perceptual candidate
        ↓
authority: none
        ↓
optional explicit adoption
        ↓
lawful later operand
```

Core law:

> **Let emergence create candidates, not counterfeit ancestors.**

Therefore keep distinct:

```
GENERATIVE ANCESTRY
what operands and operators actually made the object

CURRENT PERCEPTUAL DECOMPOSITION
what parts or relations are presently recognized in it
```

The second may change. The first must not.

## Primary failure mode: recursive laundering

The new dual-projection system creates a dangerous failure shape:

```
verbal pass invents X
        ↓
mathal projection formalizes X
        ↓
formal notation makes X look established
        ↓
verbal return cites the formal result
        ↓
recursion makes X look old / cross-confirmed
```

This must remain impossible constitutionally.

Core law:

> **Cross-representational agreement is still not witness.**

Even if verbal, mathal, and spatial projections all retain `X` for many recursive breaths, `X` does not thereby become observed, ancestral, authorized, or historical.
