# Sigil Language — Geometry Becomes Speech

> **Status:** primitive-incubator language hypothesis, 2026-08-22. This page records a newly visible compositional possibility. It does **not** yet promote the P0–PF catalogue into universal eCODEsystem law or require any host project to implement it.

## The hinge

The sixteen primitives are no longer merely a symbol catalogue.

Once the catalogue is combined with declared morphology operators and ordered composition, it begins to have the minimum anatomy of a language:

```
primitive        ≈ letter / root / lexical atom
operator         ≈ verb / inflection
ordered relation ≈ syntax
host context     ≈ pragmatics
receipt lineage  ≈ attributable semantics
history          ≈ tense / aspect
refusal / cut    ≈ negation / unavailable continuation
```

The claim is deliberately narrow:

> **Geometry can carry grammar without pretending geometry is universal meaning.**

The symbols are invented Static Collective conventions. Their usefulness must be earned by repeated work, not by how ancient, occult, elegant, or familiar they look.

## Morphology

The existing shape operators become grammatical actions:

```
TRANSLATE  ROTATE  REFLECT  SCALE
REPEAT     OVERLAP LIGATE   CUT
OPEN       CLOSE   NEST     BRANCH
MERGE      PROJECT
```

An operator changes how a primitive participates while declaring what it preserves and what it loses.

That is close to morphological inflection in ordinary language: the root remains attributable while its role or form changes.

## Syntax

Order matters.

```
P8 -> CUT -> PE
```

is not necessarily the same expression as:

```
PE -> CUT -> P8
```

Likewise:

```
NEST(P8, PC)
```

is structurally different from:

```
OVERLAP(P8, PC)
```

The grammar therefore cannot collapse into a bag of attractive icons. A useful expression needs recoverable ordering, scope, inputs, and transformation history.

## Semantics without counterfeit authority

Meaning lives in layers.

A primitive may have a stable proposed semantic core, but the host system determines what consequence — if any — that meaning is allowed to have.

```
shape meaning
    !=
execution authority
    !=
identity proof
    !=
historical ancestry
```

This is especially important for Witness Sigils. A witness-locked sigil may project a canonical digest. A free creative sigil may use the same geometric alphabet without representing any digest at all. Those two channels must remain visibly and mechanically distinguishable.

## Time becomes grammar

The Haunted Toaster already exposes an unusually useful temporal vocabulary:

```
hold
  -> apparition
  -> resonant overlap
  -> dissolve | scar | succession
```

This suggests that a sigil language may eventually have something analogous to **aspect** rather than only nouns and verbs:

* `hold` — persistent present;
* `apparition` — temporary appearance;
* `scar` — past event with surviving residue;
* `succession` — one topology becoming the current authoritative descendant;
* recursive return — recurrence with declared difference.

The important point is not literary analogy. It is that a geometric expression can preserve **what happened to it through time** rather than describing only its final shape.

## Toaster consequence — topology sentences

The strongest Toaster use is not sixteen additional effects.

It is to let candidate geometry be composed as a sentence before rendering:

```
roots
  + morphology
  + ordered composition
  + temporal behavior
        ↓
normalized topology expression
        ↓
image / typography / material / weather / motion inhabit it
```

That means existing Toaster actions suddenly read as language operations:

* **MUTATE** — inflect or alter one expression while preserving attributable ancestry;
* **CROSS** — compose two named expressions into a child;
* **STOMP** — seek a deliberately distant expression under bounded rules;
* **Ghost Topology** — introduce temporal clauses: apparition, overlap, scar, succession;
* **six-up candidate ecology** — not merely six pictures, but six alternative utterances descended from one selected thought.

This could eventually allow the six-up interface to show six different grammatical consequences of one selected topology rather than six opaque random-looking visual outcomes.

## Sentences are not receipts

A generated topology expression may be receipt-bound, but the expression itself is still not authority.

For a witness-derived specimen:

```
canonical digest
  -> frozen witness projection
  -> derived topology expression
  -> renderer execution
  -> child receipt
```

The frozen witness projection must remain recoverable. Mutation happens downstream. A mutated descendant must never impersonate the canonical witness sigil that seeded it.

## Dialects should be allowed

If this becomes real, different projects should be allowed local dialects before any shared language is frozen.

For example:

* Haunted Toaster may interpret `CUT` as visual rupture;
* TranchNode may interpret the same abstract operation as preserved discontinuity in a projection;
* Project0 may never need a rendered form at all;
* a printed score might use only a small accessible subset.

Shared roots do not require identical consequences.

A healthy grammar may therefore look like:

```
shared primitive question
        ↓
project-local interpretation
        ↓
project-local consequence
        ↓
portable witness of what happened
```

rather than one universal rendering engine.

## Growth discipline

Do not freeze a language because it is exciting.

Let actual use reveal which distinctions survive.

For each recurring expression, preserve:

```
form
first attested use
host / context
intended work
actual perceived work
transformations
variants
misreadings
repeated uses
candidate semantic core
promotion status
```

This mirrors the existing Decompression Lab discipline for living words: use comes before canon.

## Candidate next specimens

Three experiments could tell us whether this is genuinely language-like rather than merely combinatorial:

1. **Comprehension:** can a person recognize recurring topology expressions across different render skins?
2. **Composition:** do ordered primitive/operator combinations produce distinguishable, reusable visual consequences?
3. **Productive novelty:** can a never-before-seen expression still feel interpretable because its parts and grammar are familiar?

The third is the strongest test.

A real language does not only let us recognize old sentences. It lets us understand new ones.

## Compact law

> **The sigils began as recognition marks. The primitives became letters. The operators gave them verbs. Order gave them syntax. History gave them tense. Now the question is whether repeated use can give them a living language without ever giving the language counterfeit authority.**
