# Attributable Becoming — Identity, Participation & History

> **Status:** incubating crossing law. Full Bowl 001 supplies concrete counterexamples; portability is not yet established.

## Compression

A consequential claim about a world can fail in at least three separable ways:

```
identity
   !=
participation
   !=
history
   !=
authority
```

The working reconstruction is:

```
stable coordinate + world head
        -> exact resolved object

exact resolved object + observed binding
        -> attributable participation

attributable participation + ordered inert dispositions
        -> reconstructible becoming
```

Each layer answers a different question:

1. **Identity / resolution** — which exact object is being referenced?
2. **Participation / binding** — did that exact object actually participate in this crossing?
3. **Trajectory / history** — what consequential path followed participation?
4. **Authority** — what, if anything, was empowered to decide or act?

None should be silently inferred from another.

## Candidate crossing invariant

**Inference, not doctrine:**

> Every consequential cross-world claim should remain reconstructible as an exact resolved object, an attributable proof of actual participation, and sufficient ordered dispositions to recover its material trajectory.

A shorter form is:

```
which thing
+
which actual crossing
+
what happened
```

This should remain a crossing invariant or receipt obligation unless repeated pressure proves it belongs in a shared primitive vocabulary.

## Three failure modes

```
coordinate without binding
-> authentic-looking detached reference

binding without phases
-> correct participant, opaque becoming

phases without stable identity
-> detailed history attached to the wrong thing
```

A fourth anti-confusion remains:

```
identity + participation + history
!= authority
```

Perfect provenance does not manufacture warrant.

## Same visible state, different attributable world

A particularly strong next specimen is:

```
World A
admit -> warrant -> attempt -> success -> visible state S

World B
admit -> warrant -> attempt -> fail -> lawful recovery -> visible state S
```

If the final visible projection is equal while the receipts preserve a materially relevant difference, then the bounded conclusion is:

```
same visible state
!= necessarily
same attributable world history
```

The distinction must be more than log-string inequality. At least one owner-recognized path-dependent difference should survive: scar, cost, recovery receipt, later reachability, obligation, refusal residue, confidence posture, or another material consequence.

If no such distinction survives, the correct result is `unresolved`.

## Ordering without a global clock

Reconstructible becoming does not require universal timestamps.

The witness only needs enough ordering to establish the consequential path, for example:

```
phase_0 ≺ phase_1 ≺ phase_2 ≺ phase_3
```

Causal or phase order is sufficient where wall-clock total order is unnecessary or unavailable.

## Free Graph boundary

Free Graph owns portable provenance/traversal semantics. Project0 owns encounter addressing. Corpus owns admission, warrant, attempt, and outcome semantics. Full Bowl owns the integration test and crossing evidence.

## Terminology warning — lens

In bidirectional programming, a lens often implies both a read projection and a write-back operation.

That implication is unsafe here unless explicitly gated.

For eCODE / Free Graph, the intended contract should remain:

```
projection lens
= read-only typed decoder

No Put.
No mutation.
No warrant.
No consequence.
```

Any transition from projection to consequence requires a separately owned gate and receipt.

## Promotion gate

Do not promote this candidate merely because Full Bowl produced a compelling hostile specimen.

1. deterministic success of the exact-binding discriminator;
2. deterministic success of the phase-history discriminator;
3. one second materially different consumer reproducing the separation law;

> **Same object is not the same encounter. Same encounter is not the same becoming. Same becoming is not the same authority. Same visible state is not necessarily the same world.**
