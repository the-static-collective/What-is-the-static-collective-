# HAUNT v0.1 — Cross-Appliance Memory Language

Status: **executable Phonograph proof; reciprocal Toaster admission door recorded; Toaster production behavior still gated**

## Primitive

Haunted Toaster and Haunted Phonograph may share **portable encounter memory without sharing execution authority**.

```
Toaster encounter
  → bounded memory capsule
  → Phonograph influence-only proposal context
  → deterministic musical mutation route
  → Phonograph receipt + return residue
  → Toaster influence-only admission door
```

Founding law:

> **The appliances share memory, not authority.**

## Return residue

The `.haunt.json` return capsule:

* names `haunted-phonograph` as origin;
* remains `influence-only`;
* names the completed receipt as the encounter rather than confusing source identity with encounter identity;
* preserves unresolved harmony alternatives by reference;
* records consumed sibling capsules only as `influenceOnlyRefs`;
* does not invent a new creative invitation on its own.

A legacy rerun over the same output stem removes stale HAUNT sidecar residue, so an earlier encounter cannot impersonate the current run.

## Refusal / negative-space behavior

HAUNT preserves unresolved and refused neighboring worlds as navigable residue without upgrading them into source truth.

```
unresolved source-facing evidence
  ├─ proposal-world A → completed
  ├─ proposal-world B → completed
  └─ proposal-world C → refused
```

Fruitfulness changes memory about the encounter. It does not retroactively prove which interpretation the source “really was.”
