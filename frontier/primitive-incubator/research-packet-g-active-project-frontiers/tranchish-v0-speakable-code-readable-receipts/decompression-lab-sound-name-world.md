# Decompression Lab — Sound → Name → World

**Status:** Tranchish design probe / research-derived / no executable authority

The Tolkien language-making research surfaced a useful distinction for Tranchish:

> **A language can grow meaning before it freezes meaning.**

We are calling that growth **decompression**.

That is **our analytical term**, not Tolkien's. Tolkien supplied several of the process clues: attention to sound-form apart from ordinary meaning, the relation between language-making and mythology, the idea that a name can precede the story, and invented languages with actual histories, speaker communities, sound change, scripts, registers, secrecy, translation, and divergence.

## The core split

Wild Tranchish may grow like this:

```
resonant sound / phrase
    ↓
wild word or name
    ↓
association / image / situation
    ↓
repeated human use
    ↓
mutation / branching
    ↓
emergent semantic center (maybe)
    ↓
canonicalization proposal (optional)
```

Canonical Tranchish remains much stricter:

```
canonical sentence
    ↓
deterministic parse
    ↓
typed proposal
    ↓
separately constituted authority
    ↓
consequence / refusal / failure
    ↓
receipt
```

The two paths may meet only at an explicit boundary.

## What Tolkien helps us see

### Sound can be a seed without being a definition

The `cellar door` tradition matters because it isolates the experience of sound-form from ordinary semantic content.

A Wild Tranchish word may therefore begin as something people want to say before anyone can state its final definition.

That does **not** make the sound intrinsically meaningful, true, or executable.

```
beautiful / striking sound
  -> worth trying
  != meaning
  != truth
  != authority
```

### Names can attract worlds

Tolkien explicitly linked language-making with mythology and repeatedly described names/languages as foundational to his stories.

The useful transfer is not “invent lore for every word.”

It is:

> **A small form can become a stable attractor around which more structure accumulates.**

That structure might be a project behavior, UI metaphor, category of residue, social convention, repeated workflow, or previously unnamed distinction.

### Words can have ancestry instead of only definitions

Tolkien's languages feel deep partly because related forms participate in historical change.

For Tranchish, a future lexicon should be able to preserve:

```
first attestation
speaker / context
variants
semantic drift
misunderstandings
borrowings
rejected senses
descendants
```

The word's history is part of the object.

### Speaker ecology matters

Tolkien's languages belong to different peoples, eras, regions, prestige systems, secrets, and relationships.

Tranchish can likewise distinguish:

```
project-local use
human-local use
model paraphrase
joke / mnemonic use
technical use
canonical executable use
```

A form can be real in one of those layers without becoming universal in all of them.

### Representation is not the underlying language

Tolkien's translation conceit is particularly resonant here: reader-facing English can represent Westron, while Old English can represent Rohirric relationships.

For Tranchish:

```
spoken sentence
  != typed parse
  != authority
  != receipt
```

The goal is lawful relationship and round-trip legibility, not collapse.

## Decompression vs canonicalization

This may be the most useful distinction from the whole research pass.

**Decompression** can branch.

It may increase associations, meanings, stories, jokes, and local variants. It can remain unresolved.

**Canonicalization** must narrow.

It must identify one inspectable semantic contract and fail closed when materially different readings remain.

So:

> **Wild Tranchish gets richer by branching. Canonical Tranchish gets safer by narrowing.**

## First living-language witness

Do not build another parser yet.

Watch a handful of words already emerging naturally:

```
Selador
inslice
deephaunt
```

For each one, record actual uses rather than assigning a definition first:

```
form
first_attested_use
speaker / context
felt meaning
work done by the word
variants
misunderstandings
repeated uses
candidate semantic core
canonicalization status
```

A useful experiment should include all three outcomes:

* one word that stabilizes around a useful distinction;
* one that branches into multiple live meanings;
* one beautiful word that simply fails to recur.

Dead branches are evidence too.

## Boundaries

This note does **not** propose:

* Tolkien vocabulary inside executable Tranchish;
* Quenya/Sindarin imitation;
* phonaesthetic beauty as semantic evidence;
* automatic canonization by usage frequency;
* model familiarity as authority;
* fictional ancestry represented as real project history;
* changes to the Cellar Door execution boundary.
