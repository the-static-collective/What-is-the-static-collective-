# Research Packet G — Active Project Frontiers

These leaves are not generic primitive seeds. They are **active project-backed frontiers** whose canonical design, implementation, tests, or issue state lives in an owning repository.

This packet is transitional navigation.

Use it when a project idea is still genuinely frontier work but should no longer look like an ownerless primitive. When the work lands as durable evidence, move its GitBook witness to Evidence or Project State. When the project repository fully owns the material, GitBook may keep only a compact orientation witness.

```
GitBook projection != project authority
project-backed != cross-project Pattern
landed specimen -> Evidence candidate
```
