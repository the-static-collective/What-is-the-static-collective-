## Boundary first

The Dead Sea Scrolls are not one book and Qumran is not one doctrine. A useful scholarly first partition distinguishes biblical manuscripts, wider Second Temple Jewish literature, and texts associated more specifically with sectarian/community life. Even clearly sectarian material varies internally.

So the operation is not:

```
800-ish texts
  ↓
ONE SECRET THEOLOGY
```

It is:

```
many attributable texts
  ↓ relational clustering
candidate compression
  ↓
rebuild predicted branches
  ↓
measure residuals / false fits
```

If the compression cannot fail, it is not compression. It is projection.

## PEEL — candidate sectarian root

The strongest current root-question is:

> **How can covenant continuity remain lawful when the inherited center is judged out of alignment?**

This applies primarily to the sectarian/community layer, not automatically to every manuscript found in the caves.

The pressure decomposes as:

```
CENTER JUDGED COMPROMISED
    ├── temple / priesthood contested
    ├── law / interpretation contested
    ├── calendar / time contested
    ├── identity / purity contested
    └── present age judged misaligned

            ↓ compress

PRESERVE SOURCE
BOUND / WITHDRAW COMMUNITY
RE-READ SOURCE AS PRESENT INSTRUCTION
EMBODY INTERPRETATION IN PRACTICE
CONSTITUTE TIME / ORDER
AWAIT / PREPARE FOR RESTORATION
```

## Rebuild from the root

If the root is useful rather than merely vague, it should regenerate recognizable families:

```
PRESERVE SOURCE
  → biblical manuscripts
  → especially dense use of Deuteronomy / Isaiah / Psalms

  → pesharim

  → progressive-revelation / legal interpretation

CONSTITUTE BOUNDED COMMUNITY
  → Community Rule
  → initiation / ranks / discipline
  → purity practice

RECONSTITUTE SANCTUARY WITHOUT OWNING TEMPLE
  → prayer / liturgy
  → community-as-temple language
  → temple criticism / alternative sacred order

CONSTITUTE TIME
  → calendrical texts
  → festival / priestly ordering

LOCATE THE PRESENT INSIDE AN ENDING
  → War Scroll
  → messianism
  → resurrection / restoration
  → eschatological interpretation

PREPARE THE WAY
  → wilderness self-location
  → Isaiah 40 activation
```

The point is not that every branch belongs to one author or one historical moment. The point is to test whether one relational pressure explains why otherwise different materials become useful together.

## Why Qumran is gold

Qumran is valuable precisely because it can punish our method. Scholarship repeatedly emphasizes the eclectic character of the collection and the danger of reading more uniformity into it than the evidence warrants.

That makes it an unusually good pressure world for relational resonance:

> **Can we compress without harmonizing?**

If yes, the method may be useful elsewhere.

If no, Qumran should be allowed to break it.
