# Resonant Disturbance v0 — Body Law

Status: **project-backed architecture checkpoint; implementation not yet landed**

Canonical project issue: [Haunted Toaster #187](https://github.com/the-static-collective/the-haunted-toaster/issues/187)

Repository design/plan checkpoint: [Haunted Toaster PR #188](https://github.com/the-static-collective/the-haunted-toaster/pull/188)

Project implementation authority remains in GitHub. This page is a bounded field projection.

## The missing organ

Haunted Toaster now has increasingly clear separation among three useful organs:

```
SENSE
  #183 Specimen Pulse
  #184 Perceptual Reflex Layer
        ↓ testimony

BODY
  Resonant Disturbance v0
        ↓ causal history

MEMORY
  #174 HAUNT return capsules
  #151 lineage / Elsewhere
```

The new seam is the middle one.

> **The Toaster may be disturbed before it is rendered. Recoil may restore present shape; witnessed disturbance remains in history.**

This is not a new visual effect. It is a deterministic body law that can eventually make visual consequence more causal without granting sensors or renderer-local state new authority.

## Why it is separate from sensing

Specimen Pulse remains a sense:

```
VSPantry attached audio
  → deterministic clip-relative witness
  → influence-only testimony
```

Resonant Disturbance answers a different question:

> Given one already-admitted pressure, what may happen inside a finite declared Toaster body?

The sensor does not prescribe an effect. Raw sensor/model/audio state does not become ambient evaluator or renderer state.

## Why it is separate from rendering

The first v0 implementation is pure data only:

```
declared body envelope
  + admitted fixture pressure
        ↓
load
        ↓
threshold crossing
        ↓
declared transfer
        ↓
recoil / settling
        ↓
ordered addressed history
```

It does **not** modify:

* accepted `VisualScore`;
* `ResolvedTimeline`;
* preview;
* production renderer;
* source-song audio;
* VSPantry execution;
* renderer policy.

Visible consequence remains separately constituted.

## Structural law

A body declares the complete finite possibility envelope before pressure enters:

```
cells_after = cells_declared
couplings_after ⊆ couplings_declared
```

A disturbance may activate only declared paths. It may not invent a cell, coupling, threshold, transfer law, pressure source, or authority.

The first evaluator stays deliberately mechanical and inspectable:

* safe integer load;
* positive thresholds;
* bounded transfer;
* explicit recoil;
* deterministic cell/coupling ordering;
* each cell crosses at most once in v0;
* finite event budget;
* explicit terminal state;
* canonical plan hash.

## History is not current state

The important conceptual distinction is:

```
current body state != event history
```

A recoil may return present load to baseline, but the threshold crossing and transfer remain part of what happened.

Two evaluations may therefore settle into the same current state while remaining historically different worlds.

That gives the Toaster a real place for **scar** before scar becomes an aesthetic instruction.

## Independent reproduction

Project0's L-Branch and Snap-State experiments are design lineage and cross-domain evidence only.

Haunted Toaster does not import Project0 as a runtime dependency and does not borrow Project0 execution authority. It independently reproduces the narrow law it needs in Toaster grammar.

The name `Resonant Disturbance` is intentional: Toaster already has `primitiveField.dynamics = "snap"`, while Project0 separately owns `Snap-State v0.1`. Keeping the names distinct protects ontology and provenance.

## First specimen

The implementation plan uses a tiny three-cell body:

```
A --AB--> B --BC--> C
```

with fixed thresholds, transfer quantities, recoil, and one fixture pressure.

The proof should establish:

```
pressure
→ threshold
→ declared transfer
→ second threshold
→ recoil
→ settled
```

alongside negative/contrast cases for:

* below-threshold settling;
* undeclared endpoints;
* cycles;
* event-budget exhaustion;
* hostile representation;
* same current state with materially different causal history;
* exact replay.

## Future visible coupling

Only after the existing renderer/foreign-material execution gates permit it may a separate adapter map accepted disturbance history into the already-existing Ghost Topology vocabulary:

```

        ↓

        ↓
```

Resonant Disturbance therefore does not create another topology system.

A topology lock remains stronger than any future body-to-topology coupling.

## MOLT and continuity

MOLT is not implemented here.

The body plan should simply preserve enough explicit before/after/history evidence that a later Typed Continuity adapter can distinguish what was preserved, transformed, broken, reconstituted, or merely represented differently.

Final-state similarity alone does not establish creature identity.

## Stop condition

The v0 body law is complete only when Haunted Toaster can truthfully prove, entirely upstream of rendering:

> **A finite declared creature body can receive one admitted pressure, cross deterministic thresholds, transfer disturbance only along declared paths, recoil, settle or exhaust within a finite budget, and preserve the exact ordered causal history that happened.**

Until then, this page remains a project-backed frontier projection rather than executable truth.
